# infrastructure/service/support

Apoio reutilizado pelos services.

- `AuthenticatedUserValidator.java`: valida perfil e usuário ativo.
- `ChamadoAccessSupport.java`: resolve o chamado acessível ao perfil.
- `InputValidationSupport.java`: normaliza texto obrigatório e valida tamanho/bytes.
- `PageResultMapper.java`: `Page` → `PageResult`.
